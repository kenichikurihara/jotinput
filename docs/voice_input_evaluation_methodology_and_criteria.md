# JotInput 音声入力独自アルゴリズム評価基準・評価セット仕様書

## 1. 評価の目的と方針

JotInput に組み込まれている独自アルゴリズムおよびヒューリスティクスが、**「意図した補正・最適化を確実に実行できること（再現率 / Positive Recall）」** と **「正当な発話や通常のタイピングを破壊しないこと（特異度 / Negative False-Positive Resistance）」** の双方を定量的に評価・検証するための仕様を定めます。

---

## 2. レイヤー別 評価指標と基準 (KPI & Evaluation Criteria)

| レイヤー | 機能・アルゴリズム | 主な評価指標 | 合格基準 (Pass Criteria) |
|---|---|---|---|
| **L1. Acoustic / VAD** | 動的ノイズフロア & 打鍵抑制 | ・打鍵中（300ms以内）の音声発火抑止率<br>・マイクロポーズ（200ms）での継続発話維持率 | **100%** (打鍵起因の誤発火ゼロ)<br>**100%** (200ms未満で音声が切断されないこと) |
| **L2. Hotwords** | In-Beam デコードバイアス | ・未知語・固有名詞の認識再現率<br>・tokens.txt外トークンの安全な除外率 | **100%** (語彙外トークンによるクラッシュゼロ) |
| **L3-1. Context Aware** | 前後文脈による同音異義語・異体字解決 | ・文脈に沿った同音異義語の選択精度<br>・前文の異体字（渡邊/齋藤等）への追従精度 | **100%** (キーワード合致時の置換成功率) |
| **L3-2. Numeral Utils** | 助数詞・単位付数字のアラビア数字正規化 | ・単位付き漢数字の変換率 (Positive)<br>・四字熟語・慣用句の誤変換防止率 (Negative) | **100%** (50件以上の単位ケースで完全一致)<br>**100%** (保護語彙の誤爆 0件) |
| **L4. Punctuation** | 音声記号コマンド & 自動句読点復元 | ・音声コマンド置換率 (まる/てん/かいぎょう等)<br>・保護語彙（天気/まるで等）の誤置換防止率<br>・文末述語に対する「。」挿入精度 | **100%** (67ケース全テストパス)<br>**100%** (保護語彙の誤爆 0件) |
| **L5. IME Arbitration** | タイピング中音声入力調停キュー | ・入力中文字（Pre-edit）の非破壊率<br>・確定後の音声キュー追記コミット順序整合性 | **100%** (文字化け・破壊 0件、順序整合 100%) |

## 3. 評価セットの設計仕様 (Evaluation Set Design)

各機能に対して、以下の2軸で構成されたテストケース群を作成します：
1. **Positive Cases (機能発火テスト)**: 正しくアルゴリズムが発動し、期待通りの形式に変換・調停されるか。
2. **Negative Cases (誤爆防止・堅牢性テスト)**: 類似した音韻や文字列を含むが、変換してはならないケースを誤って破壊しないか。

### 3.1. 評価セット一覧

#### (1) 日本語句読点・音声記号コマンド評価セット (`JapanesePunctuationEvaluationSet`)
- **Positive コマンド**: 
  - `お疲れ様でした まる` → `お疲れ様でした。`
  - `よろしくお願いします くてん` → `よろしくお願いします。`
  - `さて てん 次の話題ですが` → `さて、次の話題ですが`
  - `明日の予定はどうですか はてな` → `明日の予定はどうですか？`
  - `素晴らしい発表でした びっくりまーく` → `素晴らしい発表でした！`
  - `ここで一旦区切ります かいぎょう 新しい段落です` → `ここで一旦区切ります\n新しい段落です。`
- **Positive 文末・読点自動補完**:
  - `明日は雨が降ります` → `明日は雨が降ります。`
  - `ご連絡ありがとうございます` → `ご連絡ありがとうございます。`
  - `しかし問題があります` → `しかし、問題があります。`
  - `時間がないので急ぎます` → `時間がないので、急ぎます。`
- **Negative 語彙保護ケース (厳格保護)**:
  - `てんき（天気）`, `てんねん（天然）`, `まんてん（満点）`, `こうさてん（交差点）`, `じゅうてん（重点）`, `10点`
  - `まるで`, `いちがん（一丸）`, `ひのまる（日の丸）`, `だんがん（弾丸）`
  - `ですから`, `ですので`, `ますが`, `ますます`

#### (2) 助数詞・単位・漢数字正規化評価セット (`JapaneseNumeralEvaluationSet`)
- **Positive 単位変換**:
  - 重さ: `五キロ` → `5キロ`, `五百グラム` → `500グラム`, `三トン` → `3トン`
  - 長さ: `十メートル` → `10メートル`, `三センチ` → `3センチ`, `五キロメートル` → `5キロメートル`
  - 年号・日時: `西暦二千二十六年` → `西暦2026年`, `昭和六十四年` → `昭和64年`, `午後三時半` → `午後3時半`
  - 通貨・割合: `百五十万円` → `150万円`, `二十パーセント` → `20パーセント`, `三割引き` → `3割引`
- **Negative 慣用句保護**:
  - `一期一会`, `一石二鳥`, `十人十色`, `五分五分`, `三日月`, `一番`, `危機一髪`, `天下統一`, `百発百中`

#### (3) 前後文脈による同音異義語・異体字評価セット (`ContextAwareEvaluationSet`)
- **同音異義語 (きしゃ/かがく/かいとう/いどう)**:
  - 文脈: `平素は大変お世話になっております。今後のご発展をお祈り申し上げます。` + ASR: `きしゃの皆様` → `貴社`
  - 文脈: `新聞朝刊に掲載予定の記事について取材を行いました。` + ASR: `きしゃクラブ` → `記者`
  - 文脈: `実験室にて新素材の高分子化合物を合成しました。` + ASR: `かがく反応` → `化学`
  - 文脈: `宇宙や自然の法則を探求する学術研究です。` + ASR: `かがくの進歩` → `科学`
- **異体字・人名ハーモナイゼーション**:
  - 文脈: `以前ご一緒した渡邊さんの件ですが、` + ASR: `来週から渡辺さんが` → `渡邊さん`
  - 文脈: `担当の齋藤先生にご連絡差し上げました。` + ASR: `斉藤先生` → `齋藤先生`

#### (4) 音声・タイピング調停評価セット (`VoiceInputArbitratorEvaluationSet`)
- **未確定入力中の音声到着**:
  - タイピング中（`あめ` 未確定）に音声認識結果（`がふっています`）が到着。
  - `composingText` を破壊せずキューに格納。
  - ユーザーが「雨」に確定した直後にキューがフラッシュされ、最終コミットが `雨がふっています` となること。

#### (5) VAD・タイピング音抑制評価セット (`StreamingVadEvaluationSet`)
- **無音・打鍵音での非発火**:
  - 完全無音データ（振幅0）を1秒間入力 → 発話チャンク生成ゼロ。
  - `notifyUserTyping(300)` 発行直後の打鍵相当パルス音入力 → 発話開始判定が抑制されること。
- **発話と無音ポーズ切り出し**:
  - 600msの有音（大振幅）に続いて500msの無音を入力 → 正確に1つの発話チャンクがコールバックへ渡されること。
